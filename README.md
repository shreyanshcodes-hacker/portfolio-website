# ShreyanshCodes — Personal Portfolio

A personal portfolio website showcasing the work, skills, projects, and creative journey of **Shreyansh Jaiswal**.

The website uses a dark, futuristic visual style with neon accents, animated backgrounds, interactive project cards, and responsive layouts.

## ✨ Features

- **Personal homepage:** Introduction, profile, skills, and contact information.
- **Animated interface:** Particle background, custom cursor, typing animation, and scroll-reveal effects.
- **Projects section:** Dynamic project cards with categories, search, and filtering.
- **Project details:** Interactive modal with descriptions, highlights, and project links.
- **Blog and updates:** Timeline-style updates section.
- **YouTube section:** Featured video cards and channel link.
- **Contact section:** Contact form interface and social links.
- **Admin page:** Project and blog data management interface.
- **Responsive layout:** Designed to work across desktop and mobile screens.

## 🛠️ Technologies

The repository uses:

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage
- Google Fonts
- SVG icons and animations

No frontend framework or package installation is required for the basic website.

## 💾 Project Data

The portfolio uses browser LocalStorage to store project and blog data.

Project data is managed through JavaScript functions in `script.js`. Changes saved in LocalStorage are browser-specific and are not automatically synchronized across devices.
